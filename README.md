# Urmi Homemade Cake Website

A responsive static cake shop website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website content
- `style.css` — layout and responsive styling
- `script.js` — product filters and WhatsApp/Facebook order links

## Publish with GitHub Pages
1. Sign in to GitHub and create a **Public** repository named `urmi-homemade-cake`.
2. Upload all three website files (`index.html`, `style.css`, `script.js`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. Your website should be available at:
   `https://sia75.github.io/urmi-homemade-cake/`

## Important customizations before publishing
- In `script.js`, check the WhatsApp number in `BUSINESS.whatsapp`. It is currently set to `8801785235997`, the international form of `01785235997`.
- The Facebook page link is already added.
- Cake prices are sample starting prices. Update them in `index.html` to your real prices.
- Replace the sample cake photos with your own cake photos when ready. The current photos load from Unsplash and require an internet connection.
- You can change cake names, descriptions and prices directly in `index.html`.

## Test locally
Open `index.html` in a browser. For best results, upload all files together and test the published GitHub Pages URL.
